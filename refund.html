Refund Policy

Last updated: September 2026

This is a general policy. The actual terms for a paid project are set out in the written agreement for that project, and take priority over this page.

Before work starts

Cancellation or refund of a deposit before work has started depends on the terms agreed for that specific project.

After work begins

Once work has started, any refund reflects the work already completed and the terms agreed for the project. Design time, drafts and revisions already delivered are generally not refundable.

Deliverable issues

If a delivered file or design doesn't match the agreed brief, contact Omar Osama promptly so the work can be reviewed and, where appropriate, corrected.

How to request a review

Email omar.osama2011@yahoo.com with the project name and a description of the issue.

This website's information should be reviewed against applicable Egyptian law and the actual terms used for each paid project.
